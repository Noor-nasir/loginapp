# 🔐 Login App

An Android application with a complete user authentication system including Login, Register, and Home screens built with Java.

---

## 📌 About The Project

This Android app implements a full authentication flow allowing users to register an account, log in securely, and access a home screen. Built using Java in Android Studio.

---

## 🚀 Features

- User Registration screen
- User Login screen
- Home screen after successful login
- Input validation
- Clean and simple UI

---

## 🛠️ Built With

- **Java**
- **Android Studio**
- **XML Layouts**
- **Android SDK**

---

## 📱 Screens

| Screen | Description |
|--------|-------------|
| Login | User enters credentials to sign in |
| Register | New user creates an account |
| Home | Dashboard after successful login |

---

## ⚙️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Noor-nasir/loginapp.git
   ```
2. Open in **Android Studio**
3. Connect an Android device or start an emulator
4. Click **Run** ▶️
